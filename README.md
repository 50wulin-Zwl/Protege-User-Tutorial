# 三国人物关系本体：Protégé 中文学习示例

这是一个配合中文教程使用的三国人物关系本体示例。`增强三国本体.owx` 采用 OWL/XML 格式，围绕人物、势力、武器和坐骑建立类、属性与个体，并通过规则演示 Protégé 中的本体推理。配套 PDF 按界面页面讲解术语、操作位置和练习步骤。

本项目供本体建模与 Protégé 操作练习。人物关系、武力值和教学角色均是示例数据，不作为三国史实依据。

## 本体内容

从 OWX 文件中的声明统计，本体包含 **12 个类、11 个对象属性、6 个数据属性、2 个自定义注释属性和 19 个命名个体**。主要示例如下：

- **类与个体**：`人物`、`武官`、`猛将`、`势力`、`武器`、`马`；刘备、关羽、张飞、赵云、诸葛亮、蜀及坐骑和武器等个体。
- **对象属性**：`使用`、`骑乘`、`忠诚于`、`执掌`、`属于`、`结义`、`指挥链上级`等，涵盖逆属性、对称性、传递性和属性链。
- **数据属性**：`字`、`武力值`、`是否主公`、`演示评分`等，用于演示文本、整数、布尔值和小数。
- **其他教学示例**：等价类、互斥类、基数约束、键、同一与不同个体、否定属性断言，以及中文 `rdfs:label`、`rdfs:comment` 和教学提示。

例如，本体没有直接声明赵云属于 `人物`、`武官` 或 `猛将`。它记录了赵云使用龙胆枪、骑乘白龙马、忠诚于刘备，且武力值为 97；配合等价类和属性定义，供推理机计算这些类型。`骑乘` 的值域为 `马`，因此白龙马的类型也可由该关系推断。`忠诚于 ∘ 执掌 → 属于` 则用于演示人物与蜀的关系推导。这些是本体设计的预期推理示例，具体显示取决于所用推理机和 Protégé 版本。

## 快速开始

1. 安装 **Protégé Desktop 5.x**。教程以该版本系列为对象，不同版本的菜单和插件可能有所差异。
2. 在 Protégé 中选择 **File → Open**，打开 [`增强三国本体.owx`](增强三国本体.owx)。建议先用 **File → Save As** 另存练习副本。
3. 在 **Active Ontology** 查看中文总说明与统计信息；依次进入 **Classes**、**Object Properties**、**Data Properties** 和 **Individuals by class** 浏览类、属性及断言。
4. 在 **Reasoner** 中选择 **HermiT** 并启动推理，比较 **Asserted**（显式）与 **Inferred**（推断）结果。可重点查看赵云、白龙马和 `蜀方人物`。
5. 在 **DL Query** 中逐条输入 `猛将`、`武官`、`蜀方人物` 或 `人物 and (使用 some 武器)`，执行后查看个体结果。查询文字需要手动输入，不会随 OWX 文件自动填入。

建议按 [中文教程](Protege_中文逐页功能教学手册_重新生成(1).pdf) 的顺序操作。教程还解释了 `some`、`only`、`exactly` 等逻辑表达式，以及中文标签未显示、推理结果为空、缺少 OntoGraf 插件等常见情况。教程提到的部分界面特性是知识补充，OWX 文件并未为每一种特性都设置示例。
